# Проверка новой оболочки LuCI на роутере — 2026-09-30

Проверка выполнена только на чтение на OpenWrt 25.12.5. Новая оболочка
подтверждена наличием `.rmm-nav-enhanced`, sidebar/mobile navigation и русского
dashboard. Версию установленного пакета отдельно через пакетный менеджер
в этом проходе не сверяли. Настройки, службы, пакеты не менялись, диагностика
и Wi-Fi scanning не запускались.

## Успешные проверки

- Проверены 11 страниц на viewport 320, 390, 768, 1024, 1440 px, высота 800 px:
  обзор, RMM dashboard, система, интерфейсы, DHCP, Wi-Fi, firewall,
  автозапуск, диагностика, RMM агент, DDNS.
- На всех страницах ширина документа совпала с clientWidth:
  305/375/753/1009/1425 px соответственно. Горизонтального скролла документа нет.
- Desktop header фиксированный, ширина 236 px, содержимое начинается с x=236.
  Sidebar имеет собственную вертикальную прокрутку для всех пунктов меню.
- На 768 px Tab с триггера «Статус» переводит фокус на видимый «Обзор»
  (left 158, right 360), aria-expanded=true. Escape закрывает список,
  возвращает фокус на «Статус» и устанавливает aria-expanded=false.
- Все четыре группы раскрываются кликом и помещаются в viewport
  при 320, 600, 768 и 899 px. Escape закрывает списки.
- На 390 px mobile submenu занимает x=12..363, заканчивается на y=735;
  bottom nav начинается на y=743. Body резервирует 57 px под панель.
- На прямых адресах проверенных страниц активная ссылка имеет aria-current=page.
- Dashboard показывает русские заголовки, «Обновление каждые 30 секунд» и
  пояснение, что WAN — состояние интерфейса, а не проверка Интернета.

## Оставшиеся дефекты и ограничения

1. P1: после входа через `/cgi-bin/luci/` активного пункта нет
   (число aria-current=page равно 0). Подсветка по pathname не учитывает
   начальный alias. Нужна связь со штатным разрешённым маршрутом LuCI.
2. P2: широкое содержимое прокручивается через общий #view. На 320 px:
   обзор 612, интерфейсы 674, DHCP 1071, Wi-Fi 534, firewall 822,
   автозапуск 736, диагностика 462, DDNS 987 px при ширине #view 281 px.
   Следует заменить общий overflow на компоненты таблиц/вывода и
   подготовить мобильные строки и вертикальные группы диагностики.
3. P2: размеры touch-контролов остаются задачей. Предыдущая проверка
   входа подтвердила кнопку 36 px, mobile-поля 42 px; ожидаемая высота
   комфортных auth-контролов 42 px.
4. Физический телефон, max-device-width cascade, настоящий 200% zoom,
   OpenWrt 24.10, ошибки RPC/ACL и сложные диалоги не проверены.

Временный viewport после проверки сброшен. Вкладка оставлена на dashboard.
